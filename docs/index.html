Overview of Video-IFBench. Video-IFBench evaluates instruction following in video understanding through Single, Multi, Selection, and Nested instructions. Its construction pipeline combines video annotation, task and constraint sampling, complex instruction generation, checklist construction, programmatic processing, and human verification. Extensive evaluation shows that current MLLMs still struggle with strict satisfaction, especially as constraints accumulate or conditional structures require evidence-grounded branch selection.

Evaluation Protocol

Each response is first checked for task-level coverage. Active checklist items are then evaluated with an LLM judge using video-grounded context or with deterministic verifiers for programmatically checkable constraints.

TCSR

(1/N) ∑i ti · (1/ni) ∑j cij

Task-gated average constraint satisfaction. It measures how many checklist items are satisfied after the active task passes.

TISR

(1/N) ∑i ti · ∏j cij

Task-gated strict instruction satisfaction. Every active checklist item must pass simultaneously.

Task pass rates are relatively stable for capable models, while strict instruction satisfaction drops sharply as constraints accumulate. For example, Gemini-3-Pro falls from 62.7 TISR at 1–4 constraints to 46.9 at 9+, and Qwen3-Omni-30B-A3B-Instruct falls from 40.1 to 3.5.
