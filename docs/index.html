Overview

Following the whole instruction—not just answering the question

Video-IFBench tests whether multimodal large language models can understand a video, execute one or more requested tasks, and satisfy semantic and formatting constraints at the same time.

01

Real video scenarios

706 videos span 10 domains, grounding every instruction in visual and temporal evidence.

02

Compositional instructions

Instructions combine 32 task types with 39 semantic and format constraint categories.

03

Constraint-level diagnosis

A hybrid evaluator reports both fine-grained constraint success and strict instruction success.

Benchmark design

Four instruction structures, increasing compositional pressure

01Foundation

Single

One video-grounded task paired with one or more explicit response constraints.

02Composition

Multi

Multiple independent tasks must all be completed in a single coherent response.

03Conditional

Selection

The correct task or response path depends on evidence identified in the video.

04Hierarchy

Nested

Tasks and constraints are embedded hierarchically to test structured execution.

Coverage

A broad taxonomy for precise failure analysis

The benchmark crosses video domains, task types, instruction structures, and constraint categories instead of collapsing instruction following into a single prompt style.

Evaluation protocol

A hybrid evaluator that checks execution and compliance

Each response passes through a task-execution gate before semantic, video-grounded, and deterministic constraints are scored.

Input

Model response

Generated from the video and instruction.

→
Stage 1

Task execution

Verify that every requested task was attempted.

→
Stage 2

Semantic checks

LLM-based judging for meaning and video grounding.

Stage 3

Rule checks

Deterministic validation for objective constraints.

TCSR

Task Constraint Success Rate

Fine-grained success across task-specific constraints.

TISR

Task Instruction Success Rate

Strict success only when the full instruction is satisfied.

Open evaluation toolkit

Run Video-IFBench with an OpenAI-compatible endpoint

The public toolkit supports resumable inference, optional ASR, hybrid scoring, and metric summaries.

git clone https://github.com/Alexios-hub/Video-IFBench.git
cd Video-IFBench
pip install -e .
huggingface-cli download Alexislhb/Video-IFBench \
  --repo-type dataset \
  --local-dir data/Video-IFBench
video-ifbench-run \
  --dataset-root data/Video-IFBench \
  --output-dir outputs/model_name \
  --api-base http://localhost:8000/v1 \
  --model model_name \
  --media-mode video-url \
  --concurrency 32 \
  --resume
video-ifbench-score \
  --response-dir outputs/model_name \
  --output-json outputs/model_name/_instruction_following_report.json \
  --judge-api-base http://localhost:8001/v1 \
  --judge-model judge_model_name \
  --concurrency 16

video-ifbench-summarize \
  --report outputs/model_name/_instruction_following_report.json \
  --model-name "model_name" \
  --format latex

See the repository README for ASR, retry, frame-fallback, and thinking-mode options.
